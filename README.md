# Cancer Mortality Dashboard- Tableau | Cisco Data Analytics
This dashboard explores cancer survival patterns by age, gender, cancer type, and state. It visualizes distribution of deceased VS survived patients, identifies high-risk age groups and cancer types, and highlights regional differences.
### Dashboard Preview
![Cancer Dashboard] (Dashboard%201.png)
### Key Insights
- Analysis of treatment types and survival status
- Cancer type breakdown by gender
- Age and mortality patterns
